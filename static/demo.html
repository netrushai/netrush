Demo mode

Every message, as the customer sees it

In the demo nothing is really sent. Every SMS and WhatsApp the system sends lands on this phone instead: booking confirmations, door codes, login codes, membership reminders and refunds. It updates live.

Demo logins

Suggested walkthrough (5 minutes)

  1. Book a court with any name and a mobile number. Pay on the test gateway.
  2. Watch the confirmation and door code arrive on this phone.
  3. Type the code on the door keypad. It opens from 10 min before the slot. Try a wrong code too.
  4. Log in to the member portal as the member, then renew online (₹2,000 / month).
  5. Open the admin: today's bookings, a phone reservation without payment, analytics, and the health check.
  6. Cancel a booking from its confirmation page. The refund message arrives here.
